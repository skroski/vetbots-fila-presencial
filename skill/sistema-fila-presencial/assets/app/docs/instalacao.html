Instale e aprenda a usar a fila da clínica

Em poucos passos você instala, coloca a cor e o logotipo da clínica e já sabe emitir e chamar senhas. Quer ser guiado? Aperte o botão e ouça a explicação de cada passo.

Ler o passo a passo

A narração usa exclusivamente áudios MP3 do Fish Audio incluídos neste pacote. O guia visual continua disponível mesmo sem áudio.

  • 🧾 Recepção/Emite senhas e organiza a fila
  • 📺 Telão da TV/tvMostra as chamadas e os vídeos
  • 🩺 Chamador/chamarO veterinário chama com 1 clique
  • 🖐 Totem/totemO tutor retira a senha sozinho
  • 📊 Métricas/metricasQuanto tempo a fila demora
  • 🎨 Ajustes/configCor, logo, vídeos e salas

1Instalar

Feito uma única vez no computador que ficará ligado na clínica (o “servidor”). Escolha o caminho mais fácil para você: pedir a um agente de IA ou instalar com o Node.js.

Opção A · Peça a um agente de IA (o mais simples)

Funciona com Claude Code, Codex e Antigravity com Gemini. Você escreve em português e o agente confere o Node.js, instala, liga o sistema e mostra o endereço de cada tela.

  1. Abra o agente dentro da pasta do sistema

    • Claude Code: no terminal, dentro da pasta, digite claude.
    • Codex: no terminal, dentro da pasta, digite codex.
    • Antigravity (Gemini): abra a pasta no Antigravity e use o chat do agente (ou digite gemini no terminal).

  2. Peça assim, em português

    Copie e cole este pedido no chat do agente e aperte Enter:

    Instale o sistema de fila presencial e me mostre os endereços.

    Se o agente estiver aberto em outra pasta e a skill do sistema já estiver instalada nele, peça assim:

    Use a skill sistema-fila-presencial e instale a fila na clínica.

    Depois é só responder às perguntas dele. Pedidos úteis a qualquer momento: “Faça um backup agora.” · “A TV não abre o endereço.” · “Faça o sistema ligar junto com o computador.”

    Se faltar o Node.js, o agente avisa e explica como instalar (Opção B, passo 1). Seus dados nunca são apagados. Quando ele mostrar a lista de endereços, pule para o passo 2 · Abrir as telas.

Opção B · Instale você mesmo com o Node.js

  1. Instale o Node.js

    É o programa que faz o sistema funcionar. Baixe a versão LTS em nodejs.org e instale clicando em “Avançar” até o fim.

  2. Coloque a pasta do sistema no computador

    Descompacte o arquivo ZIP (ou copie a pasta do pendrive) em um lugar fácil, como a Área de Trabalho.

  3. Inicie o sistema

    Abra a pasta e dê duplo clique em iniciar.bat. Na primeira vez ele instala tudo sozinho (1 a 2 minutos). Deixe a janela preta aberta: ela é o sistema funcionando.

    Se o Windows perguntar sobre o Firewall, marque Redes privadas e clique em Permitir. Sem isso a TV não consegue abrir.

    Dê duplo clique em iniciar.command. Se o macOS bloquear, clique com o botão direito no arquivo e escolha Abrir. Deixe a janela aberta.

    Abra o terminal dentro da pasta e rode os dois comandos abaixo. Deixe o terminal aberto.

    npm install
npm start

    Deu certo quando aparecer “Fila Presencial no ar!” com uma lista de endereços. Anote o número que começa com 192.168…: é o IP do servidor e você vai usar no próximo passo.

Opção C · Aplicativo para instalar (Windows, macOS e Linux)

Não precisa instalar o Node.js: o aplicativo já leva tudo dentro. Baixe o arquivo do seu sistema na página de versões (Releases):

  • Windows: Fila-Presencial-…-win-x64.exe. Se aparecer “O Windows protegeu o computador”, clique em Mais informações → Executar assim mesmo. O instalador já libera o Firewall para redes privadas.
  • macOS: …-mac-arm64.dmg (Apple M1/M2/M3/M4) ou …-mac-x64.dmg (Intel). Arraste para Aplicativos. Se o macOS bloquear, abra Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.
  • Linux: .deb para Ubuntu/Debian (duplo clique ou sudo apt install ./arquivo.deb) ou .AppImage para as demais (dê permissão de execução e abra).

Fechar a janela não desliga a fila: ela continua no ícone perto do relógio (ou no Dock, no Mac). Para desligar, use Encerrar a fila. O menu Fila → Conectar TV, totem e consultórios mostra os endereços para os outros aparelhos.

2Abrir as telas

Cada tela é um endereço que você abre no navegador de qualquer aparelho ligado no mesmo Wi-Fi ou cabo do servidor.

Aparece na janela do sistema ao iniciar. Se perdeu: Windows ipconfig · macOS ipconfig getifaddr en0 · Linux hostname -I
TelaQuem usaEndereço

Digite o IP acima e a tabela monta o endereço de cada tela. Toque em Copiar e cole no navegador do aparelho. No próprio servidor você também pode usar http://localhost:3000.

3Configurar a clínica

Abra a tela Ajustes (/config). Tudo muda na hora, em todas as telas, sem reiniciar.

🎨 Cor da marca

Escolha uma cor pronta ou use o seletor. O sistema cria sozinho os tons claros e escuros. Experimente aqui (nesta página só como exemplo):

  • Aparência: cor, nome da clínica e logotipo (PNG, JPG, WebP ou SVG; fundo transparente fica melhor).
  • TV & Vídeos: envie vídeos MP4, reordene com as setas e escolha o layout da TV.
  • Consultórios & Salas: cadastre cada sala onde há atendimento.
  • Serviços & Prefixos: serviços e a letra de cada senha (por exemplo A, B, C).
  • Sistema: backup do banco de dados.

Os vídeos tocam sem som de propósito, para o aviso sonoro da chamada ser bem ouvido.

4Aprender a usar

Veja o caminho de uma senha e o que cada pessoa da equipe faz.

O caminho de uma senha

  1. 1O tutor chega e pega a senha na recepção ou no totem.
  2. 2Ele espera no saguão e acompanha a TV.
  3. 3O veterinário aperta Chamar Próximo da Fila.
  4. 4A TV mostra a senha, o consultório e toca um aviso sonoro.
  5. 5A consulta é iniciada e depois finalizada.

🧾 Recepção /

  1. Clique em Nova Senha.
  2. Escolha o serviço e a prioridade: Normal, Preferencial ou Emergência.
  3. Digite o nome do tutor (obrigatório) e o do pet.
  4. Se quiser, escreva o motivo e escolha uma sala específica. Sem sala, vale a Fila Geral.
  5. Clique em Emitir Nova Senha de Atendimento.

No topo, quatro quadros mostram quantos aguardam no saguão, quantos estão em consulta, os atendidos hoje e os chamados na TV.

Na lista da fila há botões para chamar no telão, transferir para outra sala ou serviço e imprimir o cupom. Use a busca para achar por senha, tutor ou pet.

🩺 Chamador do consultório /chamar

  1. Confira em “Você está atendendo em” se a sala é a sua.
  2. Clique em Chamar Próximo da Fila. A TV avisa na hora.
  3. Quando o paciente entrar, clique em Iniciar Consulta.
  4. No fim, clique em Finalizar Consulta.

Não ouviram? Repetir Chamada. Ninguém apareceu? Não Compareceu. Precisa mandar para outra sala? Transferir Atendimento.

🖐 Totem /totem

Tela de toque para o tutor.

  1. O tutor toca em “Toque para retirar senha” no serviço que precisa.
  2. Digita o nome dele e do pet.
  3. Toca em Emitir Senha Agora. A senha sai na impressora, se houver.

Em um caso grave, existe o botão vermelho Emergência Veterinária.

📺 Telão da TV /tv

Ninguém precisa mexer: ela mostra a chamada atual bem grande, as chamadas recentes e os próximos, e passa seus vídeos entre as chamadas.

O botão de privacidade esconde os nomes dos tutores e mostra só a senha.

📊 Métricas /metricas

Para o gestor ver, no dia a dia, o tempo médio da chegada até ser chamado, a duração média da consulta e o volume de atendimentos por serviço.

Treine antes de abrir a clínica: emita uma senha na recepção, chame no chamador e veja a TV reagir.

5TV, consultório e totem

Cada aparelho só precisa abrir o seu endereço no navegador.

📺 TV da sala de espera

  1. Abra o navegador da TV e digite o endereço da tela /tv.
  2. Coloque em tela cheia.
  3. Dê um clique na tela para liberar o som.
  4. Salve nos favoritos e desligue a proteção de tela.

🩺 Consultórios

Em Ajustes → Consultórios & Salas, cada sala tem o botão Link do chamador. Abra esse link no computador do veterinário e salve nos favoritos.

🖐 Totem

Abra /totem no tablet da entrada e deixe em tela cheia. Se tiver impressora de cupom, deixe-a como padrão do computador ou tablet.

6Seus dados e segurança

Tudo fica guardado na pasta data, dentro da pasta do sistema.

💾 Backup

  • Automático: o sistema faz uma cópia por dia e guarda as últimas 14.
  • Manual: Ajustes → Sistema → Baixar backup do banco.
  • Trocar de computador: copie a pasta data para o novo.

🔒 Segurança

  • Use somente na rede da clínica. Nunca abra a porta para a internet.
  • Para impedir que alguém mude cor, vídeos e salas, o técnico pode definir um PIN (veja “Para o técnico”).

Problemas comuns

Quase tudo se resolve em um destes itens.

A TV ou o tablet não abre o endereço

Confira se o aparelho está no mesmo Wi-Fi do servidor, se o IP está certo e se o endereço termina com :3000. No Windows, o Firewall precisa estar liberado para Redes privadas.

Fechei a janela preta e o sistema parou

Ela é o sistema. Abra o iniciar.bat (ou iniciar.command) de novo e deixe aberta. Seus dados continuam guardados.

Não toca som na chamada

Os navegadores só liberam o som depois de um clique. Dê um clique na tela da TV uma vez.

O vídeo não toca na TV

Converta para MP4 H.264 com áudio AAC (o técnico tem o comando abaixo, em “Para o técnico”). As chamadas continuam funcionando mesmo sem o vídeo.

Aparece “Node.js … é antigo demais”

Instale o Node.js LTS atual em nodejs.org (versão 22.16 ou maior) e abra o sistema de novo.

“A porta 3000 já está em uso”

Outro programa usa essa porta. Veja a dica em “Para o técnico”.

A numeração das senhas reinicia em horário estranho

A virada do dia usa a hora do servidor. Confira data, hora e fuso do computador.

Para o técnico

Opções avançadas. Quem só vai usar o sistema pode pular esta parte.

Instalar com Git ou Docker

Git:

git clone https://github.com/skroski/vetbots-fila-presencial.git
cd vetbots-fila-presencial
npm install
npm start

Docker (sobe sozinho quando o computador liga; os dados ficam em data/):

docker compose up -d --build

Para ver os endereços: docker compose logs.

Porta, PIN dos Ajustes e fuso horário

Outra porta: PORT=3001 npm start (Windows cmd: set PORT=3001 && npm start). Lembre de trocar 3000 pelo número novo nos endereços.

PIN para proteger os Ajustes: ADMIN_PIN=1234 npm start. No Docker, ajuste o fuso com a variável TZ.

Linux com firewall ativo:

sudo ufw allow 3000/tcp
Converter vídeo para a TV (ffmpeg)

Formato mais compatível com Smart TVs: MP4 H.264 + AAC, 1080p. Com o ffmpeg instalado:

ffmpeg -i entrada.mov -c:v libx264 -preset medium -crf 23 -vf "scale=1920:-2" -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart saida.mp4
Atualizar, iniciar com o computador e tela cheia fixa

Atualizar (a pasta data/ nunca é sobrescrita):

git pull
npm install
npm start
  • Windows: Win+R → shell:startup → coloque um atalho do iniciar.bat.
  • macOS: Ajustes do Sistema → Geral → Itens de início → iniciar.command.
  • TV estável: mini-PC ou Fire TV com o Fully Kiosk Browser abrindo /tv ao ligar.
  • Totem iPad: ative o Acesso Guiado. Android: Fully Kiosk Browser.
  • Impressão direta: inicie o Chrome com --kiosk --kiosk-printing e deixe a impressora térmica (58 ou 80 mm) como padrão.

Se aparecer “A interface ainda não foi gerada”, rode npm run build e inicie de novo. Restaurar backup: pare o sistema, troque data/fila.db pelo arquivo do backup e inicie.
