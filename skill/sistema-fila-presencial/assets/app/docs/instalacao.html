Instale a fila presencial da clínica em minutos

Recepção, telão de TV com vídeos MP4, chamador de consultório, totem e métricas. Tudo em um programa só, na rede da clínica, com a cor e o logotipo da sua marca.

Ver o passo a passo
  • 🧾 Recepção/Emite senhas e organiza a fila
  • 📺 Telão da TV/tvChamadas + vídeos em loop
  • 🩺 Chamador/chamarVeterinário chama com 1 clique
  • 🖐 Totem/totemTutor retira a senha sozinho
  • 📊 Métricas/metricasEspera, atendimento, ausências
  • 🎨 Ajustes/configCor, logo, vídeos, salas

1Requisitos

Um computador que fique ligado durante o expediente (o servidor) e os aparelhos da clínica na mesma rede.

💻 Computador servidor

  • Windows 10/11, macOS ou Linux
  • Node.js 22.16 ou superior (versão LTS), ou Docker
  • Pode ser o PC da recepção ou um mini-PC dedicado
  • Espaço em disco para os vídeos da TV

Baixar o Node.js (nodejs.org): instalador padrão, avançar até o fim.

📡 Rede da clínica

  • Servidor, TV, tablet e consultórios no mesmo Wi-Fi/cabo
  • Internet não é necessária para operar
  • Recomendado: reservar um IP fixo para o servidor no roteador

Para conferir o Node: abra o terminal (ou Prompt de Comando) e digite node -v. Deve aparecer v22.16 ou maior (v24 também serve).

2Obter o pacote

Escolha o jeito mais fácil para você.

Com Git

git clone https://github.com/skroski/vetbots-fila-presencial.git
cd vetbots-fila-presencial

Sem Git (ZIP ou pendrive)

No GitHub: Code → Download ZIP e descompacte. Ou copie a pasta do pacote por pendrive para o computador servidor.

Depois de descompactar, todos os comandos abaixo são executados dentro dessa pasta.

3Instalar e iniciar

Escolha seu sistema. A primeira vez instala tudo; depois é só iniciar.

Sem terminal: dê duplo clique em iniciar.bat. Na primeira vez ele instala tudo (1 a 2 minutos). Deixe a janela preta aberta: ela é o servidor.

Pelo terminal (PowerShell ou Prompt de Comando, dentro da pasta):

npm install
npm start

Na primeira execução o Windows pergunta sobre o Firewall: marque Redes privadas e permita. Sem isso a TV não consegue abrir.

npm install
npm start

Ou dê duplo clique em iniciar.command (se o macOS bloquear, clique com o botão direito → Abrir).

npm install
npm start

Libere a porta no firewall se estiver ativo:

sudo ufw allow 3000/tcp

Ideal para deixar fixo no computador da recepção: sobe sozinho quando o computador liga.

docker compose up -d --build

Os dados ficam na pasta data/ do projeto. Para ver os endereços: docker compose logs.

Quando estiver no ar, o terminal mostra "Fila Presencial no ar!" e a lista de endereços com o IP do computador. Esse é o sinal de que deu certo.

4Abrir as telas

Digite o IP do computador servidor e a tabela monta os endereços certos para copiar.

Aparece no terminal ao iniciar. Ou: Windows ipconfig · macOS ipconfig getifaddr en0 · Linux hostname -I
TelaQuem usaEndereço

Mesma rede e mesma porta (3000). Se a porta estiver ocupada, inicie com outra: PORT=3001 npm start e troque 3000 pelo número novo.

5Cores, logotipo e vídeos

Tudo pela tela Ajustes (/config), sem mexer em código e sem reiniciar.

🎨 Cor da marca

Escolha uma cor pronta ou use o seletor. O sistema gera sozinho os tons claros e escuros e todas as telas abertas mudam na hora. Experimente aqui (só esta página muda; no sistema, todas as telas):

🖼 Logotipo

Em Ajustes → Aparência → Enviar logotipo (PNG, JPG, WebP ou SVG, até 5 MB). Aparece na recepção, na TV, no totem, na aba do navegador e, se quiser, no cupom impresso. Fundo transparente fica melhor.

🎬 Vídeos da TV (MP4)

Em Ajustes → TV & Vídeos → Enviar vídeos (MP4). Envie vários, reordene com as setas, pause ou exclua. A TV toca em sequência e em loop. Dois layouts:

  • Vídeo + painel: vídeo à esquerda, chamada sempre visível à direita.
  • Vídeo em tela cheia: a chamada assume a tela por alguns segundos e o vídeo volta.

Formato mais compatível com Smart TVs: MP4 H.264 + AAC, 1080p. Para converter qualquer vídeo (precisa do ffmpeg):

ffmpeg -i entrada.mov -c:v libx264 -preset medium -crf 23 -vf "scale=1920:-2" -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart saida.mp4

Os vídeos tocam mudos por padrão, para o sinal sonoro da chamada ser bem ouvido. Também em Ajustes: salas, serviços e letras das senhas (A, B, C, X...), cupom e PIN para proteger os Ajustes.

6TV, consultórios e totem

Cada aparelho só precisa abrir um endereço no navegador.

📺 Smart TV da sala de espera

  1. Abra o navegador da TV e digite o endereço /tv.
  2. Toque em tela cheia.
  3. Dê um clique com o controle na tela: libera o som.
  4. Salve nos favoritos e desative a proteção de tela.

Mais estável: um mini-PC ou Fire TV com o Fully Kiosk Browser abrindo /tv sozinho ao ligar.

🩺 Consultórios

Em Ajustes → Consultórios & Salas, cada sala tem o botão Link do chamador. Crie um atalho desse link na área de trabalho do veterinário (Chrome: ⋮ → Transmitir, salvar e compartilhar → Criar atalho → “Abrir como janela”).

🖐 Totem (tablet)

Abra /totem no tablet. iPad: ative o Acesso Guiado. Android: Fully Kiosk Browser.

Impressora térmica (58 ou 80 mm): defina como padrão e inicie o Chrome com --kiosk --kiosk-printing para imprimir sem janela.

7Backup, atualização e início automático

Seus dados ficam na pasta data/: banco, logotipo e vídeos.

💾 Backup

  • Automático: uma cópia por dia em data/backups/ (guarda 14 dias)
  • Manual: Ajustes → Sistema → Baixar backup do banco
  • Tudo junto: copie a pasta data/ para um pendrive ou nuvem
  • Restaurar: pare o sistema, troque data/fila.db pelo backup e inicie

🔄 Atualizar

git pull
npm install
npm start

A pasta data/ nunca é sobrescrita.

⚡ Iniciar com o computador

  • Docker: já inicia sozinho
  • Windows: Win+R → shell:startup → coloque um atalho do iniciar.bat
  • macOS: Ajustes → Geral → Itens de início → iniciar.command

Segurança: o sistema é feito para a rede interna. Não abra a porta na internet. Para limitar quem altera cor, vídeos e salas, defina um PIN: ADMIN_PIN=1234 npm start.

Problemas comuns

Quase tudo se resolve em um destes itens.

A TV ou o tablet não abre o endereço

Confira se estão na mesma rede/Wi-Fi do servidor e se o endereço tem o IP certo e :3000. No servidor, libere a porta no firewall (Windows: marque “Redes privadas” ao permitir o Node).

“A porta 3000 já está em uso”

Outro programa usa essa porta. Inicie em outra: PORT=3001 npm start (Windows cmd: set PORT=3001 && npm start).

“A interface ainda não foi gerada”

Rode npm run build dentro da pasta e inicie de novo.

Aparece “Node.js … é antigo demais”

O sistema usa o SQLite que já vem dentro do Node, a partir da versão 22.16. Instale o Node.js LTS atual em nodejs.org (ou use o Docker).

O vídeo não toca na TV

Converta para MP4 H.264/AAC com o comando do passo 5. A TV mostra um aviso discreto e tenta de novo; as chamadas continuam funcionando.

Não toca som na chamada

Navegadores só liberam áudio depois de um clique. Toque na tela da TV uma vez e confira o botão “Sinal Sonoro Ativo”.

A numeração das senhas reinicia em horário estranho

A virada do dia usa o fuso do computador servidor. Ajuste data/hora/fuso dele (no Docker, a variável TZ).
